# d-browser
IT IS A WEB-BROWSER WITH AN INBUILT OS
HOW TO USE:
1. DOWNLOAD THE ZIP FILE AND UNZIP IT
2. GO INSIDE THE UNZIPPEND FOLDER AND RIGHT CLICK AND THEN OPEN A TERMINAL THERE
3. THEN FOR LINUX:
 bash install-wizard.sh
4. FOR WINDOWS:
   Extract the zip, for example to C:\D-Browser. Avoid paths with unusual characters.
   
   Open the folder, click the address bar, type powershell and press Enter. In the window that opens, run:
   npm install
   npm run dist:win


to see installatio progress on linux open separate terminal and paste this:  cd ~/Downloads/D-Browser
tail -f setup.log
